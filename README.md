# Park OS — 智慧园区多维监控大屏

基于 WebSocket 实时数据推送的 IoT 监控大屏系统，集成自适应图表与智能故障诊断。

## 架构概览

```
┌──────────────────────────────────────────────┐
│  浏览器 (Vite + 原生 JS + ECharts)             │
│  ┌─────────────────────────────────────────┐ │
│  │  监控大屏                                 │ │
│  │  KPI面板 │ 折线图+饼图 │ 热力图 │ 诊断面板 │ │
│  └─────────────────────────────────────────┘ │
│         ▲ WebSocket (ws://localhost:3001)     │
└─────────┼────────────────────────────────────┘
          │  每秒推送 IoT 数据
┌─────────┴────────────────────────────────────┐
│  Node.js WebSocket Server (server/index.js)  │
│  传感器模拟 │ 故障诊断引擎 │ 告警生成         │
└──────────────────────────────────────────────┘
```

## 功能清单

| 功能 | 说明 |
|------|------|
| 📊 监控大屏 | 深色科技风全屏仪表盘，5 列 KPI 核心指标 |
| 📈 趋势折线图 | 24h 能耗 + 温度 + 湿度，双 Y 轴自适应 |
| 🍩 占比饼图 | 5 类设备环形分布，实时更新 |
| 🔥 空间热力图 | 6 区域 × 4 环境指标密度分布 |
| 🩺 智能故障诊断 | 6 条规则引擎，自动识别 PM2.5/CO₂/温湿度异常并给出建议 |
| 🔌 实时推送 | WebSocket 每秒主动推送，断线自动重连 |
| 🚨 告警中心 | 告警生命周期管理（待处理→处理中→已解决） |

## 一键启动

```bash
# 1. 安装依赖
npm install

# 2. 启动 WebSocket 数据服务（终端 1）
npm run server

# 3. 启动前端开发服务器（终端 2）
npm run dev
```

浏览器打开 `http://localhost:5173`，监控大屏即自动连接 WebSocket 并开始实时刷新。

> 如 WebSocket 连接失败（header 右侧红点闪烁），请确认终端 1 的 `npm run server` 正在运行。

## 技术栈

| 层面 | 技术 |
|------|------|
| 前端 | Vite + 原生 JavaScript + ECharts 5 |
| 后端 | Node.js + ws (WebSocket) |
| 样式 | 原生 CSS（CSS Variables + Grid + 深色主题） |
